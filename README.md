# Путь кармы v2

Статическое PWA без сервера. Все записи хранятся на устройстве (IndexedDB, запасной вариант — localStorage).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | оформление |
| `content.js` | редакционный контент (`karma-v2-content.json` + дополнительные тексты в `extra`) |
| `rules.js` | правила трека: даты, окна недели, флаг, ясность, миграция, импорт. Чистые функции, работают в Node |
| `store.js` | хранилище: IndexedDB / localStorage, экспорт, чтение старых данных |
| `app.js` | экраны и навигация |
| `sw.js` | офлайн-кэш с версией сборки и обновлением по кнопке |
| `manifest.webmanifest`, `icon-*.png` | установка на телефон |
| `img/` | фоны, путник, астролябия, значки, цифры |
| `build.py` | сборка в `dist/`: проставляет версию в `sw.js` и ссылки на файлы |
| `tests/rules.test.js` | автопроверки правил (Node) |
| `tests/e2e.py` | сценарии в браузере (Playwright, Chromium) |

## Запуск и проверка

```
python3 build.py                      # собирает dist/
cd dist && python3 -m http.server 8787   # локальный сервер (service worker нужен http)
node tests/rules.test.js              # правила
python3 tests/e2e.py                  # сценарии (сервер должен работать)
```

## Публикация

Загрузить в корень репозитория GitHub Pages всё содержимое `dist/` (файлы и папку `img/`). Старый одиночный `index.html` заменяется. После загрузки у открытого приложения появится кнопка «Обновить».

## Правки текстов

Все тексты упражнений, карточек, гипотез и подписей — в `content.js`. Пороги прогресса — в `content.js` → `progressPolicy` (это продуктовые ориентиры пилота, не медицинские критерии).
