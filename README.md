# Путь кармы v2

Статическое PWA без сервера. Все записи хранятся на устройстве (IndexedDB, запасной вариант — localStorage).

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | каркас страницы |
| `styles.css` | оформление |
| `content.js` | редакционный контент (`karma-v2-content.json` + дополнительные тексты в `extra`) |
| `rules.js` | правила трека: даты, окна недели, флаг, ясность, миграция, импорт. Чистые функции, работают в Node |
| `store.js` | хранилище: IndexedDB / localStorage, экспорт, чтение старых данных |
| `app.js` | экраны и навигация |
| `sw.js` | офлайн-кэш с версией сборки и обновлением по кнопке |
| `manifest.webmanifest`, `icon-*.png` | установка на телефон |
| `img/` | фоны, путник, астролябия, значки, цифры |
| `build.py` | сборка в `dist/`: проставляет версию в `sw.js` и ссылки на файлы |
| `tests/rules.test.js` | автопроверки правил (Node) |
| `tests/e2e.py` | сценарии в браузере (Playwright, Chromium) |

## Запуск и проверка

```
python3 build.py                      # собирает dist/
cd dist && python3 -m http.server 8787   # локальный сервер (service worker нужен http)
node tests/rules.test.js              # правила
python3 tests/e2e.py                  # сценарии (сервер должен работать)
```

## Публикация

Загрузить в корень репозитория GitHub Pages всё содержимое `dist/` (файлы и папку `img/`). Старый одиночный `index.html` заменяется. После загрузки у открытого приложения появится кнопка «Обновить».

## Данные (схема 3–5, сборка от 15.10.2026)

- Записи дня (`checkins`) хранятся по ключу `дата|сюжет` (`id`), а не по дате: вечер одного сюжета не приписывается другому, два сюжета в один день не затирают друг друга. База IndexedDB обновляется с версии 1 на 2 автоматически внутри одной транзакции; запись без сюжета получает `дата|-` и доказательством не считается.
- Действие («Сделал по-новому») и вечернее подтверждение помнят `skillId`, `experimentId`, `planVersion` на момент записи. Флаг считает только записи своего навыка; версия плана не важна (навык тот же — практика та же). Смена навыка создаёт новую версию плана, старые записи остаются за прежним навыком. У старых записей навык восстанавливается из плана, действовавшего в момент записи (`rules.backfillEvidence`); если план определить нельзя, запись в флаг не входит.
- Черновики: ключ `сценарий|сюжет|версия`, сохранение по вводу (с задержкой 0,4 с) и сразу при переходах; черновик старше 36 часов предлагается продолжить или начать заново; при ошибке хранилища черновик не удаляется.
- Импорт и восстановление (`store.replaceAll`) — одна транзакция на все хранилища: при ошибке база остаётся прежней. Файлы схемы 2 читаются и приводятся к схеме 3.
- Разрешение и план помнят версию объяснения (`permissionSource`, `experiment.hypothesisVersionId`). После смены или отказа от объяснения экран «Мой сюжет» предлагает «Оставить» (`keptFor`) или «Выбрать другое». Формулировка пользователя (`permissionSource.origin = user`) молча не перезаписывается.
- Короткий вечер — два вопроса: «Был повод и что получилось?» (повод и действие одним ответом) и трудность. Повод из дневных записей не выводится; репетиции показаны отдельно и поводом не считаются.
- Повторная проверка (сборка от 15.10, вторая): черновики прежней сборки переносятся в новую схему (`rules.migrateDrafts`), неоднозначные сохраняются текстом в Настройки → Данные → «Незаконченные записи прошлой сборки»; старые разрешения получают `permissionSource.origin = migrated` и попадают в проверку при первой смене объяснения; `validateImport` никогда не бросает исключение, UI показывает причину; навык, восстановленный задним числом (`backfilled`), для флага не считается — прошлая сборка позволяла менять навык плана на месте. Схема экспорта 4, импорт принимает 2–4.
- Заголовки пакетов карточек — нейтральные контексты («Просьбы и обязательства», «Контроль и самостоятельность»…), без утверждений о причине реакции.

## Вход v3 (15.10.2026): число пути → знакомый сценарий → учитель → урок → новый ответ

Карта пути: `start` (почему это снова происходит) → `birth` (дата, «Продолжить без даты») → `symbol` (астролябия, число, название пути, «Пропустить» анимацию) → `cards` (до 6 карточек: 4 из сценариев пути + 2 из других; без даты — 6 разных тем; свайп/кнопки/клавиши, «Не уверен», «Вернуть карточку», обучение один раз) → резюме узнавания («Да, это похоже / Уточнить / Другой сюжет») → `teacher` (кто, что повторяется, когда в последний раз, дата) → `lesson` (учитель, урок, внутри, в действии; «Это не мой урок» → альтернативы и «Пока не знаю») → главная «Сегодня на твоём пути». «Ничего не подошло» → другие сюжеты / свой случай / наблюдение. Без реального случая — наблюдение без даты старта и флага.

Данные входа: `P.onb` (шаг, колода, ответы, отмена, учитель, урок), `P.seen.swipe`; сюжет получает `scenario`, `teacher`, `lesson` (предварительный, `hypothesisId` — версия объяснения для шага «Что мне было важно»), первый план по навыку урока (`experiment.kind = first-plan`), разрешение с `permissionSource.origin = lesson`. Число влияет только на порядок первой подборки (`rules.buildDeck`); правила флага без изменений. Действующие сюжеты и записи прошлой версии новый вход не запускают.

Каталог: `tools/content_v3.py` → `content.js` (пути с `intro` и `packs`, карточки «ситуация → реакция → результат» с `recognition`, по сценарию `teacherExamples`, `lessons`, `summary`; `extra.onboarding`, `teachers`, `lessonUnknown`).

Проверка v3 (вторая сборка 15.10): «Описать свой случай» во входе — свой сценарий (`own`: текст → тема или «пока не ясно» → учитель → урок); уточнение сценария и свой случай идут через общий поток с черновиками по карточке и версии контента, этап восстанавливается после перезагрузки (`P.onb.stage`); остальные отмеченные карточки сохраняются в `P.savedScenarios` и видны в «Моём пути» («Начать с этого» закрывает текущий сюжет и ведёт к учителю); отмена последней карточки доступна и на экране выбора; расхождение урока и практики по навыку (`rules.lessonDrift`) предлагает «Уточнить урок / Сохранить формулировку», экран флага показывает урок только при совпадении навыка; урок подтверждается шагом «Что произойдёт, если отвечу иначе» при том же навыке.

## Вход v4 (15.10.2026, точность узнавания): число как интрига → сфера → событие → что задело → повторение → тема отдельно от подтверждённого резюме → учитель → урок

Карта: `start` → `birth` (дата по желанию) → `symbol` (коротко: «Твоё число — N. Найдём, с какого сюжета начать», без черт) → `area` (отношения с близкими / работа и общение / деньги и обязательства / отношение к себе / конкретная ситуация → `own` / пока трудно понять) → `cards` (события одной строкой, до 4 из сферы, «Было / Не было / Не уверен», после первого «было» — «Разобрать этот случай / Смотреть дальше», несколько «было» → «Что разберём сейчас?», остальное в «Знакомые сюжеты на потом») → `sting` («Что в этом задело сильнее всего?» с вариантами события, «В этот раз не задело» возвращает к подборке, «Другое / трудно сказать» и своими словами; «Это знакомое повторение или один случай?»; реакция по желанию) → `path` (описание темы числа отдельно; «С чего начинаем у тебя» только из подтверждённых ответов; без даты — «Точка старта твоего пути») → `teacher` → `lesson` (по значению события; без объяснения — «Первый шаг — заметить свою реакцию», без внутреннего запрета).

Данные: `scenario` хранит происхождение частей (`eventOrigin`, `meaningOrigin`: user_selected / user_written; `lesson.origin = editorial_hypothesis` до подтверждения практикой; `lesson.basis`). Каталог событий и тем: `tools/content_v4.py` (`extra.areas`, `events` с `meanings[].lessonId`, `paths[].title/description/question/offer`, `lessonObserve`). Число не влияет на подборку (`rules.buildEventDeck`).

Проверка v4 (вторая сборка): урок ищется по глобальному id (`rules.findLesson`) — направление задаёт выбранное значение события, пакет сюжета берётся по уроку, факты события сохраняются; значения без редакционного урока имеют предметное наблюдение (`meanings[].observe`: заголовок, действие, сигнал), в том числе для денежных событий — без финансовых советов; реакции заданы для каждого события (`events[].reactions`), для своего текста реакция не спрашивается; значения переформулированы на уровень «что неприятно/важно»; «было, но не задело» не входит в кандидаты (`rules.deckCandidates`), остаётся фактом и доступно для пересмотра на экране выбора.

## Вход v5 (15.10.2026, убедительный чекап, первый день и обучение)

Карта: `start` (проблема + «О подходе»: раскрываемый текст и пустой чекбокс согласия, кнопка активна только после отметки; `P.consent = {version, at}`) → `birth` → `symbol` → `area` → для «Работа и общение» `workctx` (с руководителем / с коллегами / с клиентами / в переписке / с нагрузкой и требованиями / по-разному) → `cards` (шесть событий: четыре под контекст + два соседних, `rules.buildEventDeck({area, ctx, first: 6, primary: 4})`; «Цепляет / Не цепляет / Не уверен», счётчик «1 из 6», отмена; «Выбрать из отмеченных» только после пяти ответов — первое совпадение подбор не завершает; в конце колоды — выбор фокуса или «ничего не зацепило» → другие события / другой контекст / свой случай / наблюдение) → `teacher` (контекст работы предложен к подтверждению, `extra.workTeacher`; партнёр при рабочей сфере — «Сейчас переключаемся с работы на личные отношения?» → «Да, это важнее» / «Вернуться к работе», `P.onb.areaSwitched`) → `case` («Вспомни последний случай» одной фразой с примерами; когда это было; «Такое повторяется / Это первый случай / Пока не уверен»; для своего случая текст не переспрашивается) → `sting` (что именно задело; реакция отложена на следующий день) → `summary` («Вот с чего начинаем»: сфера, учитель, повторяющийся сюжет, особенно задевает — только подтверждённое; «Да, это моя ситуация / Поправить»; тема числа — отдельной карточкой) → `lesson` («Предлагаю начать с этого урока. В течение недели проверим, подходит ли он») → `map` («Как будет устроен твой путь», `P.seen.map`) → главная.

Честные даты (схема 5): `pattern.practiceStartDate` — день, когда человек начал практику выбранного ответа (`rules.practiceStartFor`: вечерний первый запуск → завтра, ночью → сегодня); `pattern.caseDate` и `episode.dateKey` — когда был вспомненный случай; `pattern.firstDay = {kind: morning|day|evening|night|acted, date, taken, closed}`. `startDate` равен `practiceStartDate` (все правила недель, итогов и флага считают от него; `rules.flagEligibility` использует `rules.practiceStart`). Вспомненный случай не даёт дней практики, шагов и действий. Миграция: у действующих сюжетов `practiceStartDate = startDate` (`practiceStartOrigin = migrated`), история и флаги не переписываются; экспорт схемы 5, импорт 2–5. Реальная попытка («Попробовал новый ответ», не репетиция) до назначенного старта честно делает день первым (`firstDay.kind = acted`).

Состояния главной: подготовка первого вечера («Сегодня — начало твоего пути», «Твой шаг», «Завтра: <день недели, дата>», «Взять шаг на завтра» → `firstDay.taken`, без действия, вечерней оценки и шага практики; «Уже был повод попробовать?» → обычная запись действия; экран вечера до старта — «Практика начинается завтра»; после полуночи — день 1 без просроченного вечера); первый день утром («Сегодня — первый день», «Взять шаг на сегодня»); первый день днём («Попробуй шаг при ближайшем поводе», вечером без опыта — «итог не нужен»: «Был повод — подвести итог» / «Закончить знакомство» → `firstDay.closed`); обычный день.

Обучение (хранится раздельно): `P.seen.map` (карта дня), `P.seen.trail` + `P.trailTip` (три подсказки тропы: камни — только последняя явная оценка состояния, `rules.lastRating` без эпизодов; шаги — завершённые вечера; небо и флаг — «Навыки: N» вместо процента; линия тропы подписана «день практики N · проверка навыка не раньше дня 21»; до обучения и первой практики — иллюстрация без панели метрик, `.trail.bare`), `P.seen.buttons` (прямые названия «Меня зацепило» / «Попробовал новый ответ» с подписями до первого закрытого вечера или открытия «Как пользоваться»; «Сейчас тяжело» с подписью). Все подсказки повторно — `#guide` («Как пользоваться», ссылка на главной рядом с «Сегодня на твоём пути», в настройках и в «О подходе»). Существующим пользователям — карточка «Мы добавили объяснение практики» (`P.guideOffer`), без сброса сюжетов и истории. Оговорки о подходе собраны в «О подходе» (экран старта, `#about`, настройки); открытие числа, карточки, карта и главная их не повторяют.

Каталог: `tools/content_v5.py` (контексты работы `extra.workContexts`, теги `events[].ctx`, новые рабочие события в том числе «Не получаю ответ по рабочему вопросу, и моя задача зависает», тексты `onboarding.approach/workctx/case/summary/map/firstDay/buttons/trail/existing/guide`, учитель «Клиент»). Запуск генераторов по порядку: `content_v3.py` → `content_v4.py` → `content_v5.py`.

## Правки текстов

Все тексты упражнений, карточек, гипотез и подписей — в `content.js`. Пороги прогресса — в `content.js` → `progressPolicy` (это продуктовые ориентиры пилота, не медицинские критерии).
